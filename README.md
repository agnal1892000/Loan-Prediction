
# Loan Prediction Analysis

## Overview
This project analyzes a Loan Prediction dataset to understand the key factors associated with loan approval decisions.

The dataset contains applicant information such as income, education, employment status, loan amount, credit history, and property area. The project focuses on data preprocessing, exploratory data analysis, visualization, encoding, and feature scaling.
## Dataset
The dataset contains applicant information such as:
- Gender
- Married Status
- Dependents
- Education
- Applicant Income
- Coapplicant Income
- Loan Amount
- Credit History
- Property Area
- Loan Status

## Data Preprocessing
- Missing-value handling
- Mode imputation for categorical variables
- Median imputation for numerical variables
- Label encoding
- MinMaxScaler

## Data Analysis
- Univariate analysis
- Bivariate analysis
- Box plots
- Scatter plots
- Correlation heatmap
- Categorical analysis

## Key Findings
- Applicant Income and Loan Amount show a moderate correlation.
- Income and Loan Amount contain outliers.
- Graduates have more loan approvals.
- Semiurban areas have the highest approvals.
